# 实施计划：BOSS 直聘岗位收集插件

规格来源：`SPEC.md`。用户已于 2026-10-14 确认开始开发；采用规格中的默认项：Chrome / Edge 桌面版、包含职位描述、仅独立详情页。

## 组件与依赖

1. `jobs.js` 定义职位数据、URL 校验、去重更新。
2. `extract.js` 只读当前详情页 DOM，输出职位候选数据；依赖职位 URL 契约。
3. `storage.js` 包装 `chrome.storage.local`，依赖职位数据契约。
4. `csv.js` 纯函数序列化，依赖职位数据契约。
5. 弹窗连接提取、预览、保存、清单和导出。

## 阶段与检查点

1. 扩展骨架和 URL 门槛：Manifest V3 能加载，非详情页不注入。
2. 提取及保存：必填字段可修正；重复 URL 更新而非追加；保存失败有反馈。
3. 导出和清单：可删除单条；CSV 中文、换行、公式字符安全。
4. 验证：Node 测试、语法检查、构建、Chrome 手动验收说明。

## 风险与应对

- BOSS 站点当前向未登录访问返回安全页，无法在此环境核对登录后的真实 DOM。提取器使用限定区域和多个候选选择器；预览可编辑；不把通用页面标题误存为职位。交付时说明需在用户登录页面做最终手动核对。
- 弹窗关闭会中断操作：只在用户确认保存后写入；导出通过浏览器下载处理。
- 页面内容可能含恶意文本：UI 使用 `textContent` / 表单值，不把页面文字作为 HTML；CSV 做公式防护。

## 构建与验证

运行 `npm test`、`npm run lint`、`npm run build`。在 Chrome/Edge 开发者模式加载构建目录，并按 `docs/manual-acceptance.md` 检查。
