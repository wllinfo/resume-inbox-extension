# 手动验收与安装

## 安装

在项目目录执行 `npm test`、`npm run lint`、`npm run build`。打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，点击“加载已解压的扩展程序”，选择项目中的 `dist/` 目录。

## 验收步骤

1. 打开 BOSS 直聘的独立职位详情页（URL 形如 `https://www.zhipin.com/job_detail/职位ID.html`）。打开插件但不点“确认保存”，确认收集数量不变。
2. 点“提取当前职位”，核对职位名称、公司、薪资、地点、经验、学历、描述。字段识别不全时手动修正，点“确认保存”。
3. 对三个不同职位重复上述操作，确认清单有三条。对其中一条再保存，确认仍为三条且薪资等字段按最新预览更新。
4. 导出 CSV，用 Excel 或 Numbers 打开，确认中文、引号、逗号及多行描述不串列。
5. 删除一条后重新导出，确认该职位不在新 CSV 中。
6. 在 BOSS 列表页或其他网站点“提取当前职位”，确认出现提示且记录数不变。
7. 观察浏览器开发者工具网络面板：点击提取时插件不应请求其他职位页。

## 已知验证限制

开发环境访问 BOSS 直聘职位详情时被安全页拦截，自动测试使用页面结构样本。真实登录页面的字段提取结果需要按上述步骤在用户浏览器中核对；可在预览中修正未识别字段。
